# Quality and Price

A responsive static website for a retail-style product catalog and contact page, built using HTML, CSS, and JavaScript.

## Project Structure

- `index.html` — main homepage
- `main.js` — interactive behaviors and dynamic component logic
- `style.css` — site styling and layout rules
- `fonts/` — custom web fonts
- `imgs/` — images used by the site:
  - `departments/`
  - `groups/`
  - `slid/`
- `pages/`
  - `contact-us.html` — contact page
  - `products.html` — product listing page
- `video/` — project videos

## Features

- responsive design for desktop and mobile
- product gallery and category layout
- contact page with form fields
- smooth scrolling and UI interactions

## Setup and Preview

- Open `index.html` in a browser.


## Development

- Edit `style.css` for styling updates.
- Edit `main.js` for JavaScript behavior.
- Add pages under `pages/` for new routes.

## Notes

- This is a client-side static site, no backend required.
- Ensure image and video assets are correctly referenced in HTML.
